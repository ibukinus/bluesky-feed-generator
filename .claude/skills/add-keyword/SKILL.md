# キーワード追加の自動化

引数: 追加したい語（複数可）。ユーザーが rank や読みを指定していればそれに従う。

## 手順

1. **rank を判定する**（CLAUDE.md「keyword.toml の編集ルール」参照）
   - 作品名・ユニット名・キャラクターのフルネーム・楽曲名など固有性の高い語 → `rank1`
   - 姓のみ・名のみ・一般語と紛らわしい語（単独では曖昧） → `rank2`
   - 正規化形マッチで誤検出しうる語（例: 英単語 seeds → シーズ） → `rank1_surface`
   - 一般語と衝突しそうで判断に迷う場合は AskUserQuestion でユーザーに確認する。
2. **追記と検証を1コマンドで実行する:**
   ```shell
   uv run python scripts/check_keyword.py "<語>" --add <rank>
   ```
3. **「user.csv への登録が必要」と報告された場合**、読みをカタカナで決めて再実行する
   （ひらがな・カタカナのみの語は読みが自動導出されるため `--reading` 不要）:
   ```shell
   uv run python scripts/check_keyword.py "<語>" --fix --reading <読み>
   ```
4. **表記ゆれも拾うべき語**（英語表記・略称・カタカナ表記など）は、user.csv に
   「別表記 → 正規化表記」のエントリを追加して同様に検証する。既存行
   （例: `shiny colors` → `シャイニーカラーズ`）の形式に合わせること。
5. `uv run pytest` を実行し、全件パスを確認する。
6. コミットメッセージ「キーワードの追加」でコミットする（ユーザーが不要と言った場合を除く）。

## 注意

- rank1 に一般語を入れると誤検出が急増する。迷ったら確認する。
- キーワードに手動で `\` エスケープを入れない（`re.escape` 済みのため、入れるとマッチしなくなる）。
- user.csv の見出し（先頭フィールド）は小文字で書く（Sudachi は入力を小文字化して照合する）。
- 検証だけしたい場合は `scripts/check_keyword.py "<語>"`（オプションなし）で診断のみ行える。
