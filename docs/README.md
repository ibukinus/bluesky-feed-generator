# ドキュメント

このディレクトリはプロジェクトの正式な文書を管理します。文書はコードと同じリポジトリで版管理し（docs-as-code）、コード変更に文書更新が伴う場合は同じコミット/PR に含めます。

## 構成

| 場所 | 内容 | 更新ルール |
|---|---|---|
| [`architecture.md`](architecture.md) | システム構成・データフロー・設計上の注意点 | 実装の変更に合わせて常に最新に保つ（恒久文書） |
| [`reports/`](reports/) | ある時点の調査・分析レポート | `YYYY-MM-DD-題名.md` で作成し、作成後は原則編集しない（スナップショット） |
| `adr/` | アーキテクチャ上の意思決定の記録（ADR） | `NNNN-題名.md` で連番管理。決定を覆す場合は新しい ADR で Supersede する |

セットアップ手順・環境変数・エンドポイント一覧はルートの [README.md](../README.md) が唯一の情報源です（ここには重複させません）。
