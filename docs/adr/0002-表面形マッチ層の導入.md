# 0002: 表面形マッチ層（rank1_surface）の導入

- 日付: 2026-07-04
- ステータス: 採用

## 文脈

キーワードマッチングは Sudachi の正規化形（`normalized_form()`）に対して行われる。正規化は表記ゆれの吸収（`shiny colors` → `シャイニーカラーズ` 等）に有効な一方、逆方向の衝突を起こす。Sudachi のシステム辞書は英単語 "seeds" を「シーズ」に正規化するため、ユニット名「シーズ」（SHHis）を rank1 に置くと、無関係な英文投稿（"seeds" を含む）を誤検出していた。

rank2（2語以上の共起が必要）への降格も検討したが、「シーズ」単独の言及を拾えなくなり recall を犠牲にする。

## 決定

keyword.toml に **`rank1_surface`** セクションを追加する。ここに置いた語はトークンの**表面形（書かれたまま）**との完全一致（IGNORECASE）でのみ採用され、正規化形マッチの対象にならない。

- 「シーズ」を rank1 から `rank1_surface` へ移動し、表記ゆれ対応として「shhis」も追加する。
- 判定順序: rank1（正規化形）→ rank1_surface（表面形）→ rank2（正規化形・2語以上）。

## 理由

- 「シーズ」「SHHis」と書かれた投稿は引き続き単独で採用でき（recall 維持）、"seeds" の正規化衝突だけを除外できる（precision 向上）。
- 機構が汎用的なため、今後同種の正規化衝突が見つかった語も keyword.toml の編集だけで対処できる。

## 影響・トレードオフ

- `rank1_surface` の語は正規化の恩恵を受けないため、表記ゆれは吸収されない。必要な表記は個別に列挙する（例: shhis）。
- 精度をさらに上げる場合の次の手段は、曖昧な語にヒットした投稿のみ LLM / embedding で判定する二段構え（[刷新方針レポート](../reports/2026-07-03-renewal-assessment.md) の中期案）。本 ADR の範囲外とする。
